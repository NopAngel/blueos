      BLUEOS   
  Official Repository

Welcome to BlueOS! This is a Unix-inspired kernel
an educational project designed for learning.


Bug Reporting:
======================


* If you're going to report a bug or request an improvement, try sending 
an email (the email address is in the .mailmap file, by the way) or create a PR/Issue.

But please keep it brief to keep the project cleaner.
